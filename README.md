# Splitro

Progetto personale · Prodotti

App per ripartire spese di viaggio tra partecipanti, con interfaccia web e integrazione Telegram.

## Esigenza

Dividere una spesa deve essere semplice, anche quando il totale non si divide perfettamente.

## Contributo

Ho separato l’interpretazione della richiesta dalle regole di ripartizione monetaria.

## Stack

Python, FastAPI, React, PostgreSQL.

## Una scelta da raccontare

Le quote vengono calcolate in centesimi interi; il totale resta verificabile.
